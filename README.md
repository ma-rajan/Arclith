# ARCLITH

Modular Arch Linux Configuration Framework.

ARCLITH is designed to provide a structured and automated way to
install, configure, and manage an Arch Linux environment.

## Planned Features

- Automated installation
- Hardware detection
- Modular configurations
- Hyprland desktop environment
- Multiple system profiles
- Developer profile
- Cybersecurity profile
- Full profile
- Package management
- Update and uninstall support
